# THREAD&TONE Clothing Store

A responsive clothing-store website built with plain HTML, CSS and JavaScript.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your live website URL.

The demo uses remote Unsplash images, so an internet connection is required for the photos.
